1. Install the client

Download the build for this computer and put it on your PATH:

latest releases

Linux x86_64, macOS (Apple silicon and Intel) and Windows (x64 and arm64) are published as omni-sync-<version>-<target>.

2. Enroll this computer

{% if code.is_some() %}

Copy this page's address from the browser bar and run: 

omni-sync enroll --link '<paste this page's URL>'

Or enroll by hand, supplying the server URL and the code:

omni-sync enroll --server <server-url> --code <code above>
{% else %}

Once you have a link with a code, run:

omni-sync enroll --link '<the link from the dashboard>'
{% endif %}

3. Watch a folder

omni-sync add

The wizard lists the server's shared folders and asks for a local path.
