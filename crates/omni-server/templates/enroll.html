1Install the client

Download the latest release and put omni-sync on your PATH.

Linux (x86_64, arm64), macOS (Apple silicon, Intel) and Windows (x64, arm64) are published as omni-sync-<version>-<target>.

2Enroll this computer

{% if code.is_some() %}

Copy this page's address from the browser bar, then run:

omni-sync enroll --link '<this page's URL>'

Or by hand, using the server URL and the code above:

omni-sync enroll --server <server-url> --code <code above>

Once you have a link with a code, run:
